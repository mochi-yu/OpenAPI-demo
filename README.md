## OpenAPI Demo
OpenAPIを使ったWeb開発をするときのファイル類のデモです。以下の特徴があります。

- OpenAPIの仕様定義には [TypeSpec](https://typespec.io/) を利用
- バックエンドのGo言語のコード生成には [oapi-codegen](https://github.com/oapi-codegen/oapi-codegen) を利用
  - 定義したオブジェクトの型のみを生成
- フロントエンドのTSのコード生成には [openapi-typescript](https://github.com/openapi-ts/openapi-typescript) を利用
